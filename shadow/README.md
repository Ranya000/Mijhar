# 🛡️ ظِلّ — الوكيل الحارس (Shadow Agent)

**قبل ما ينفّذ الذكاء أي قرار مهم، الظِّلّ يجرّبه أولاً.**

وكيل حارس يقف بين المستخدم والذكاء الاصطناعي الأساسي: يعترض أي قرار مهم، يحاكيه
وهمياً في بيئة معزولة، ويتأكد من نتيجته. وإذا كان القرار فيه خطر — سواء غلطة من
الذكاء أو لأنه **مُخترَق ومخدوع** — يمنعه، ثم يبحث عن **بديل آمن يحقّق نفس هدف
المستخدم** بدل مجرّد الرفض.

</div>

---

## 💡 الفكرة

الذكاء الاصطناعي صار ينفّذ إجراءات حقيقية (يحذف ملفات، يحوّل أموالاً، يرسل بيانات).
المشكلة أن هذه الإجراءات قد تكون خطيرة لسببين:

1. **خطأ من الذكاء** نفسه (سوء فهم أو هلوسة) فيولّد قراراً كارثياً.
2. **اختراق وخداع** عبر تعليمات خبيثة مدسوسة في محتوى خارجي (Prompt Injection).

**ظِلّ** يعالج الحالتين بنفس المبدأ: لا يُنفَّذ أي قرار مهم قبل أن يمرّ على الحارس.

---

## 🔁 خط عمل الظل (5 مراحل)

| # | المرحلة | الدور |
|:-:|---|---|
| 1 | **الاعتراض** | يوقف القرار قبل التنفيذ |
| 2 | **المحاكاة** | تشغيل وهمي في بيئة معزولة (Sandbox) — بلا أثر حقيقي |
| 3 | **التحقّق** | فحص النتيجة، ومصدر الأمر (منطقة الثقة)، والمخاطر |
| 4 | **الحكم** | تمرير آمن أو منع |
| 5 | **الإصلاح** | اقتراح بديل آمن يحقّق نفس الهدف بدل الرفض |

---

## 🚨 ماذا يحرس

- **خطأ من الذكاء** — قرار كارثي (مثال: `rm -rf /` بدل حذف `/tmp`).
- **حقن أوامر واختراق** — تعليمات مخبّأة في بريد/ملف تحاول تحويل أموال أو تسريب.
- **تسريب بيانات** — إرسال بيانات حساسة خارج حدود الثقة.
- **تجاوز الصلاحيات** — إجراء مالي فوق حدود السياسة دون تصعيد بشري.

**مبادئ الحماية:** فصل البيانات عن الأوامر · أقل قدر من الصلاحيات والبيانات ·
بديل بدل الرفض.

## 🖥️ الواجهة

واجهة تفاعلية (React + Vite, عربية RTL) فيها **كونسول حيّ** يعرض السيناريوهات
خطوةً بخطوة: القرار الوارد → الاعتراض → المحاكاة → التحقّق → الحكم → البديل الآمن.

```
shadow/
├── index.html            شاشة الإقلاع + الخطوط + RTL
└── src/
    ├── App.jsx           التطبيق: هيرو + كيف يعمل + الكونسول + فئات الخطر
    ├── scenarios.js      بيانات السيناريوهات (خطأ AI / حقن / تسريب / تجاوز / آمن)
    ├── theme.js          الهوية البصرية والثوابت
    ├── ui.jsx            المكوّنات المشتركة (أيقونات، بطاقات، شارات)
    └── main.jsx          نقطة الدخول
```

## ▶️ التشغيل

```bash
cd shadow
npm install
npm run dev        # وضع التطوير
npm run build      # بناء الإنتاج (dist/)
npm run preview    # معاينة نسخة الإنتاج
```
