# 📧 قوالب بريد InterMission — دليل الإرسال

في هذا المجلد قالبان جاهزان بهوية InterMission (بطاقة منفصلة + لوقو النادي MIS Club جنب لوقو InterMission + لمسات ماجنتا):

> 🌗 **الوضع الداكن/الفاتح تلقائي:** البطاقة تصير داكنة إذا كان جهاز المستلم على الوضع الداكن، وفاتحة إذا كان فاتح — بدون أي إعداد منك (مدعوم بأفضل شكل في Apple Mail و iOS Mail، وجزئياً في Outlook).

| الملف | الاستخدام |
|---|---|
| `intermission-acceptance.html` | رسالة **القبول** (تهانينا 🚀) |
| `intermission-rejection.html` | رسالة **الاعتذار** (تحديث بشأن الطلب ✨) |

---

## 1) قبل الإرسال: عبّئ الفراغات

في كل قالب استبدل هذه الحقول بين الأقواس `[ ]`:

- `[اسم المتقدم]` ← اسم الشخص
- `[الرابط]` ← رابط التأكيد / رابط قناة التحديثات (في رسالة القبول)
- `[اليوم]` · `[التاريخ]` · `[الوقت]` ← موعد اللقاء التعريفي (في رسالة القبول)

💡 لو ترسلين لعدد كبير، استخدمي أداة تدعم **الدمج (Mail Merge)** حتى يتغير الاسم تلقائياً لكل شخص (الطريقة الثالثة بالأسفل).

---

## 2) معاينة القالب قبل الإرسال

افتحي ملف الـ HTML بأي متصفح (اسحبيه إلى نافذة Chrome) لترى شكله.
> ملاحظة: عملاء البريد قد يعرضون التنسيق باختلاف بسيط — القالب مبني بجداول (tables) وأنماط inline لأفضل توافق مع Gmail و Outlook و Apple Mail.

---

## 3) طرق الإرسال للفريق (اختاري الأنسب)

### الطريقة أ — Gmail (الأسهل، لعدد قليل)
1. افتحي ملف الـ HTML في المتصفح.
2. حددي كل المحتوى `Ctrl+A` ثم انسخيه `Ctrl+C`.
3. في Gmail: **إنشاء رسالة** → الصقي داخل جسم الرسالة `Ctrl+V`.
4. اكتبي عنوان الرسالة، مثلاً: `تهانينا! تم قبولك في برنامج InterMission 🚀`
5. أرسلي.

> إن ظهر التنسيق مكسوراً بعد اللصق، استخدمي الطريقة ب أو ج (ألصق النسخ لا ينقل الـ HTML بدقة دائماً).

### الطريقة ب — لصق كود HTML مباشرة (أدق)
- **Outlook / Apple Mail / Thunderbird**: بعض الإصدارات تسمح بإدراج ملف HTML كرسالة. في Thunderbird مثلاً: `Insert → HTML` والصقي محتوى الملف.
- أو استخدمي إضافة مثل **"Send HTML Email"** في Gmail.

### الطريقة ج — أداة نشرات بريدية (الأفضل لعدد كبير + دمج الأسماء) ✅
منصات مجانية/سهلة: **Brevo (Sendinblue)** أو **Mailchimp** أو **Mailtrap**.
1. أنشئي حملة/رسالة جديدة → اختاري **"Paste HTML code"** أو **"Import HTML"**.
2. الصقي محتوى ملف الـ HTML كاملاً.
3. أضيفي قائمة المتقدمين (جدول فيه: الاسم + الإيميل).
4. استبدلي `[اسم المتقدم]` بوسم الدمج الخاص بالمنصة، مثل `{{ contact.FIRSTNAME }}` في Brevo أو `*|FNAME|*` في Mailchimp.
5. أرسلي حملة تجريبية لنفسك أولاً، ثم أرسلي للجميع.

### الطريقة د — كود (لو الفريق يبي يربطه بالنظام)
مشروع الـ backend هنا Node.js، فتقدرون ترسلون عبر مكتبة **Nodemailer**:
```js
const nodemailer = require("nodemailer");
const fs = require("fs");

const html = fs.readFileSync("emails/intermission-acceptance.html", "utf8")
  .replace(/\[اسم المتقدم\]/g, applicant.name)
  .replace(/\[الرابط\]/g, confirmUrl);

const transporter = nodemailer.createTransport({ /* بيانات SMTP */ });
await transporter.sendMail({
  from: '"نادي نظم المعلومات الإدارية" <club@example.com>',
  to: applicant.email,
  subject: "تهانينا! تم قبولك في برنامج InterMission 🚀",
  html,
});
```

---

## 4) نصائح مهمة قبل الإرسال الجماعي
- ✅ أرسلي **رسالة تجريبية لنفسك** وتأكدي أن الروابط تعمل والاسم يظهر صح.
- ✅ اكتبي **عنوان الرسالة (Subject)** يدوياً — القالب لا يحتوي العنوان، هو داخل الرسالة فقط.
- ✅ استخدمي رابط **BCC** أو أداة دمج حتى لا تظهر إيميلات المتقدمين لبعضهم.
- ✅ تأكدي أن المرسِل اسمه واضح (اسم النادي) لتفادي صندوق الـ Spam.
